## 网易云登录后读取失败：新增复核

只读对照 `references/ZViewer-main/backend/src/routes/music.ts` 与 `frontend/src/modules/music/pages/MusicMyPage.tsx`：参考项目在二维码授权或旧凭据缺少资料时通过 `/user/account` 补全身份，然后读取用户歌单和收藏。TongMu 原实现保存凭据却可能没有保存用户编号，导致私人目录不能读取。
