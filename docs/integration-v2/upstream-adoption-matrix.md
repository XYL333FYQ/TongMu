# TongMu V2 upstream adoption matrix

## How to read this matrix

- This is the audit ledger: an item marked KEEP/ADOPT/ADAPT/DEFER/REJECT has been inspected at the listed implementation paths, not inferred from a README.
- **KEEP** means TongMu is already the authoritative design and must not be overwritten. **ADOPT** means the upstream behavior can be brought over with small translation. **ADAPT** means keep the semantic but redesign it for TongMu's contracts. **DEFER** requires a future trigger. **REJECT** means it is not suitable for the current product.
- `Phase` refers to `implementation-plan.md`. Status records the current implementation state after the Phase 6B-2 implementation closure; the environmental Docker execution gate remains explicit.
- Reference paths are relative to the audited source root; TongMu paths are repository-relative.

## Coverage conclusion
