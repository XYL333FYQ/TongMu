## 实际连续操作

- 创建三个演示房间，分别切换视频、音乐与投屏；大厅反映活动和在线状态。公开房间按名称/房间号发现，长中英文名称可以换行或在紧凑管理列表中截断。
- 选择内容窗口输入错误链接后显示中文原因和下一步，保留原输入；修正为公开 HLS 链接后解析、加入并立即播放。
- 内置浏览器实际解码视频为 1920×1080，`readyState=4`。返回大厅后时间从 21.64 秒继续至 32.66 秒；切到音乐时暂停，切回视频保留约 75.45 秒并等待手动继续。明确退出后 `video` 与 `audio` 元素均为 0，常驻房间条消失。
- 中文表单切换英文时保留房间名称草稿和规则选择，房间名称、用户名、媒体名称和用户聊天正文保持原样。
- 头像和外观菜单的实际 CSS 均为 `zen-dropdown-enter`、0.24 秒；关闭、快速重开、逐项出现、减少动画以及键盘归属由对应行为测试补充验证。
- CDP 触摸模拟确认 `(pointer: coarse)` 生效；大厅品牌、导航、外观、账号、语言、加入/创建/刷新/卡片入口达到至少 44×44。手机房间滚动到底后，聊天开关和发送按钮不被语音/流量浮动入口遮挡，点击标签能够实际切换开关。
- 390×420 房间设置窗口用于短高度检查：内容区可滚动，关闭、取消和保存保持在视口内。该检查不等同于真实手机软键盘。
- 个人中心的服务器文件区域只保留一个区域标题；添加文件夹窗口实际验证 Tab / Shift+Tab 循环、Escape 收起及焦点返回打开按钮，关闭的目录侧栏保持 inert。
- 登录和注册模式切换使用带图标及交互反馈的共用按钮；中英文桌面和手机布局均保存截图，并实际切换注册后返回登录，没有创建新账号。

密码错误重试、加入审核、满员/取消、登录限制、协作授权、成员请求/修改投票、代理交接、投屏停止/重启和语音释放由 `e2e/room-experience.spec.ts`、`screen-lifecycle.spec.ts`、`voice-lifecycle.spec.ts` 验证；投屏使用 canvas 流，语音使用 fake 设备。

## 验证边界

Windows 本机及 Chromium、Firefox、WebKit 引擎已有相应证据；没有认证 iOS、Android、macOS 真机或真实麦克风、扬声器、系统投屏选择器。测试来源和公开 ODC HLS 不代表所有第三方账号/网络源均已验证。用户可自定义背景、透明度、主题色和减少动画，本轮截图主要使用默认背景。
