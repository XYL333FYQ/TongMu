# 品牌与房间封面界面验收

2026-10-03，通过用户现有的内置浏览器标签检查。截图使用独立 E2E 数据目录中的三个实际房间，封面通过界面的文件选择器上传；这些演示房间不写入日常 `config` 数据库。

- `hall-zh-{width}x{height}.jpg`：16 种完整大厅布局，尺寸见 `viewport-checks.json`。覆盖 1440×900、1920×1080、2560×1080、平板、手机横竖屏、320 像素宽、短高度及 600/601、800/801、1050/1051 断点附近。
- `hall-en-1440x900.jpg`、`hall-en-dark-1440x900.jpg`：英文和暗色全页效果。
- `hall-zh-touch-390x844.jpg`：触摸模拟，三个加入按钮均为 44 像素高。结束后取消触摸模拟及视口覆盖。
- `cover-editor-zh-*.jpg`：中文封面设置在桌面、手机和短窗口中的效果；`390x420-scrolled` 是 390×420 视口截图，使用 Tab 从名称输入框进入上传按钮，滚动区域自动让按钮进入可见范围，保存/取消仍可操作。

16 种尺寸均无页面横向溢出；三个图片实际解码宽度均为 960，图片区高度均大于信息区。同排卡片的加入按钮底边对齐。长名称截为两行，完整文本保留在标题属性和 DOM。720×450 用于等效宽度重排检查，不代表操作系统的真实 200% 缩放测试。

截图是 Windows 内置浏览器的实际页面，视口和触摸模拟不等于手机或其他操作系统真机认证。Chromium、Firefox、WebKit 的独立功能验证结果见 [整改说明](../../design/room-cover-refresh.md)。截图完成后恢复正常本地服务和日常数据库。
